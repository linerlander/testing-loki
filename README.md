# testing-loki

Herramientas propias para **auditar y probar mis servidores VPS**.

> ⚠️ Uso exclusivo sobre servidores propios o con autorización expresa.
> Escanear sistemas de terceros sin permiso es ilegal.

## Scripts

- `auditar-vps.sh` — revisa un VPS propio: puertos abiertos, servicios y avisos de seguridad.

### Uso

```bash
bash auditar-vps.sh TU_IP
```
